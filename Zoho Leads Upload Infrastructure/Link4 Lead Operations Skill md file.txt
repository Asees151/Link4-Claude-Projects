5. TASK RULES

Always close Zoho auto-generated tasks: after creating leads, wait ~2s, GET Leads/{id}/Tasks, set any task whose Subject contains Important Web Lead to Status Completed.

Description must include full lead-source details, module interest, contact info, context, call goal.

Upcoming: Subject Demo with {Name} — {Company}, Status Not Started, due demo date.

For converted leads (Contacts): use Who_Id = contact id, What_Id = account id, $se_module Accounts.

6. DUPLICATE PROTOCOL

Before creating anything:

Search Leads/search?email= for each lead's email.
If not found, search Contacts/search?email= (converted leads live here; conversion removes them from Leads).
Existing in Leads → SKIP creation. If it's a re-submission with new info:
Data Sheet → Quote re-sub: UPDATE lead (Lead_Source_Information → Meta Ads Modbus Quote, rewrite description, bump to HIGH), add note titled Re-submission to Quote — HIGH PRIORITY, create Nashrah task. Do NOT re-add to Close CSV (already there).
Quote → Data Sheet re-sub (downgrade direction): SKIP entirely unless told otherwise.
Same-form re-sub with -high marker: UPDATE description to HIGH, add Re-submission — Bumped to HIGH note.
Report duplicates to Asees with what was found (source, date) before/while processing.
7. PRIORITY & RELEVANCE CLASSIFICATION
Asees marks priority inline: -high / -normal suffix on a form field (usually company or job title). Follow those markers exactly.
HydroRoot without markers: ask, don't guess.
Modbus Quote: always HIGH + Nashrah task.
Modbus Data Sheet: classify relevance yourself and mark strong fits HIGH with a RELEVANCE NOTE: in description; leave others Normal WITHOUT negative comments (cold caller verifies). Strong-fit signals: engineering/automation/integration companies, work-email domains, Director/CEO/Engineer titles, US/CA location, refrigeration/controls industries. Weak: schools, hotels, retail chains, foundations, unrelated job titles (waiter, housewife, actor), personal-only context.
Obvious spam (e.g., Company "Hollywood" / Title "Actor"): flag to Asees; skip if confirmed.
8. DATA QUALITY RULES
Generic company names break Close imports (duplicate company dedup). Rename pattern: {Person Name} ({Generic}). Applies to: Self, Self-Employed, Retired, N/A, Personal, none, Home, Independiente, Trabajo Independiente, occupation descriptions ("retired crane operator"), the person's own email in the company field, "Yes", etc. Record the original value in a NOTE.
Missing last name: infer from email prefix when plausible (e.g., rjuarez769 → Juarez (inferred)), flag in description + note + any task to verify on call. If nothing to infer, use company/placeholder in last name with note (e.g., Wayne (Marion Landing)).
Business name in person-name field: split it as First/Last (e.g., Mt. Pilchuck / Orchards), note that no person name was provided.
Phone normalization: strip parens/spaces to E.164; add +1/+52 when missing and country is clear (record it).
Country detection by phone: +52 MX, +57 CO, +91 IN, +386 SI, etc. +1: Canadian area codes (416, 437, 647, 226, 289, 365, 519, 705, 807, 905, 204, 306, 403, 587, 604, 672, 778, 709, 506, 902, 250, 867) → CA; else US. International/off-target leads: still create, flag geography in description.
Company/context research: add value-add notes when a company is recognizable (school district, Fortune 500, cannabis grow, golf course, hotel, gov agency, potential channel partner, competitor irrigation/automation co.). Flag institutional-vs-personal mismatch (big-company name + personal gmail → likely personal interest; qualify on call).
Accented/special characters are fine in Zoho — keep as submitted.

import urllib.request, urllib.parse, json, time

def get_token():
    data = urllib.parse.urlencode({"grant_type": "refresh_token", "client_id": CLIENT_ID,
        "client_secret": CLIENT_SECRET, "refresh_token": REFRESH_TOKEN}).encode()
    req = urllib.request.Request("https://accounts.zoho.com/oauth/v2/token", data=data, method="POST")
    return json.loads(urllib.request.urlopen(req).read())["access_token"]

def zoho(method, endpoint, data=None, token=None):
    url = f"https://www.zohoapis.com/crm/v2/{endpoint}"
    body = json.dumps(data).encode() if data else None
    req = urllib.request.Request(url, data=body, method=method)
    req.add_header("Authorization", f"Zoho-oauthtoken {token}")
    if body: req.add_header("Content-Type", "application/json")
    try:
        resp = urllib.request.urlopen(req); b = resp.read()
        return json.loads(b) if b else {}
    except urllib.error.HTTPError as e:
        return {"error": e.code, "body": e.read().decode()}
